# Mobile Form Exercises

A cross-platform React Native project for practicing the form exercises in the
“Get Started with React Native” presentation.

## Run the app

```bash
npm install
npx expo start
```

The app uses Expo Router. Add screens under `src/app/` and keep reusable
components and form logic outside that directory.

## Exercises

1. User registration
2. Student admission
3. Online banking transfer
4. Hospital appointment
5. Job application
6. E-commerce checkout
7. Event registration
